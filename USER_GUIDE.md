# Fairchild Frontend — Quick User Guide

## 1) Start with Search
- Go to `/search`.
- Select platform(s): **CJ**, **Impact**, or both.
- Enter a **relevant 2–3 word keyword** (best results).
- Click **Search**.

### Sample searches
- `running shoes`
- `wireless earbuds`
- `dog food`
- `nike tshirt`
- `kitchen organizer`

> Tip: Avoid long sentence-style queries in normal search. Short product-like keywords work best.

---

## 2) Select Products
- Review results in **Select Products** step.
- Tick products you want.
- Click **Review Selection**.

---

## 3) Review and Choose Template
- In **Review**, confirm selected products.
- Continue to **Select Template**.
- Choose image template and continue.

---

## 4) Post Package (Important Fields)
- In `/package`, verify generated content for each product.
- You can regenerate individual fields if needed.

### Status fields
- **Wordpress status**: `draft`, `pending`, `private`, `publish`
- **Metricool status**:
  - `draft` → sent to Metricool with `draft: true`
  - `publish` → sent with `draft: false`

### Schedule field
- Set **Metricool schedule date and time** (or regenerate).
- Keep time realistic for next-day/near-term posting.

---

## 5) Start Pipeline
- Go to **Start Pipeline** and click **Start pipeline**.
- Pipeline runs:
  1. Create post package
  2. Download/edit image
  3. Create WordPress post
  4. Schedule to Metricool

## Important runtime note
- **Stay on the same browser window/tab until pipeline completes.**
- Closing/reloading can interrupt UI tracking of run progress.

---

## Quick Troubleshooting
- If no results:
  - Try a simpler 2–3 word keyword.
  - Check platform selection.
